# Structura Edit: проверка основы

Дата: 8 сентября 2026. Проверено на macOS ARM64, Python 3.9, Qt 6.8.3,
PyVista 0.46.5, VTK 9.5.2, PyVistaQt 0.11.3, Amulet Core 1.9.35.
Используются рабочие core 0.6.0, render 0.8.0 и edit 0.1.0a1.

## Реализовано

- Компактный интерфейс на нативных Qt Widgets: меню, контекстные действия,
  поиск команд, панель 0–9 и подсказки мыши для активного инструмента.
- Непрерывный полёт WASD/стрелками, обзор мышью, ускорение, регулировка скорости,
  короткий ПКМ для меню и удержание для полёта. Перерисовка обзора объединяется
  по кадрам; потеря фокуса освобождает курсор.
- Select двумя блоками, углы и кубоид; слои остаются в 3D. Есть шесть видов и
  отключаемая мини-карта с проекциями.
- Move использует стандартный VTK Box Widget и ghost. Перенос, координаты и
  размещение курсором меняют preview; Enter применяет одну операцию. Сброс
  параметров инвалидирует незавершённый расчёт.
- Просмотр Java Anvil: выбор папки один раз, измерение, координаты, горизонтальный
  и вертикальный радиусы, Refresh в слоте 9, автоматическая подгрузка при полёте.
  Новый origin сохраняет положение и направление камеры в мировых координатах.
  Смена точки/радиуса во время загрузки отбрасывает устаревший результат.
- Сущности читаются из чанков, отдельных entity-region файлов и сохранённых
  данных игроков. Sheep, pig и player проверены с текстурами и без них;
  используется общий каталог моделей render.
- Удалена водная грань, совпадающая с гранью непрозрачного полного блока;
  грани у стекла остаются. Исправление находится в общей геометрии render.

Фикстуры мира покрывают плотную и выровненную упаковку block states, старую
обёртку Level, современную структуру секций, отрицательные координаты, внешние
entity chunks, игроков, отсутствующие и обрезанные чанки. Хэши файлов до и после
чтения совпадают. Тест WorldView запрещает редактирование источника и экспорт
выделения с отсутствующим чанком.

## Замеры

Реальный мир Java 1.21: 9 чанков, 48 × 80 × 48 ячеек ограниченного окна,
76 526 непустых блоков, три курицы и сохранённый игрок. Загрузка с геометрией
заняла 3,873 с. В последнем сценарии максимальный промежуток между событиями
16-мс таймера GUI составил 0,088 с; до оптимизации — 0,386 с.

Профиль показал повторный подсчёт материалов через отдельный объект каждой
ячейки в потоке GUI. Теперь исходные частоты считаются в worker, а дальнейший
подсчёт использует палитру и изменения. Обновление мира объединяет установку
геометрии, рамки и камеры в одну перерисовку.

Demo: открытие 1,387 с, preview замены 0,178 с. Это результаты конкретных
скрытых сценариев, не гарантия интерактивной частоты кадров или больших миров.
[Машинные результаты](structura-edit-foundation-2026-09-08.evidence.json).

## Границы этапа

Мир сейчас доступен для просмотра, выделения и экспорта. Запись patch и
согласованный режим best-effort ещё не реализованы. Refresh показывает состояние
диска; память работающей Minecraft не читается. Игроки отображаются в сохранённых
позициях со стандартной моделью; сетевой поиск скинов и симуляция отсутствуют.

Каждая загрузка пересобирает ограниченное окно, а не отдельные чанки. Очередь
хранит только последний запрос; есть бюджеты объёма и числа блоков. Следующее
направление — меши и кэш по чанкам, соседний контекст, измерение кадров и памяти
при долгом полёте. Windows/Linux и полная матрица версий миров ещё не проверены.

Anvil reader core использует read-only доступ к файлам и адаптер распаковки
Amulet 1.9.x. Используемый `_decompress` является внутренним API зависимости;
его совместимость проверяют вместе с обновлением Amulet. Штатный reader Amulet
не применён, поскольку его открытие региона может менять выравнивание файла.

Скриншоты не выполнялись. Пользовательское окно не закрывалось. Тесты схем
сохраняли результат во временную папку; сохранение мира использовалось только
для чтения. Расширенные инструменты остаются в
[плане](../../structura-edit-roadmap.md) после основы.
