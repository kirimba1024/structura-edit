# Архив Structura Edit

Исследования, старые планы и результаты отдельных прогонов. Они сохраняют
историю решений, но не описывают текущий редактор. Для обычной работы достаточно
[README](../../../README.md), [архитектуры](../../structura-edit-architecture.md)
и [ближайших задач](../../structura-edit-roadmap.md).

Архив исключён из обычного поиска через `.ignore`. Для поиска по истории:
`rg --no-ignore <запрос> docs/archive/structura-edit`.
