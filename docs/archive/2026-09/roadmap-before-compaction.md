## Актуальная очередь после обзора мира

Компактная база, кэш секций, обзор всех сохранённых чанков, HLOD, мировая карта
и детерминированное уточнение уже реализованы и измерены. Текущий контракт —
[навигация](world-navigation-plan.md), результаты —
[реализация обзора](world-overview-implementation-2026-09-11.md).
Прежние предложения о heightfield и полном запрете фонового уточнения заменены:
полёт читает готовый снимок, Minecraft перечитывается только явно.

Автономная macOS-сборка обновлена, обзор мира проверяется внутри приложения.
Проверка распакованного ZIP вне workspace прошла —
[результат поставки](macos-overview-delivery-2026-09-11.md).

Профиль Take/Apply/Undo на 24 этажах выполнен. Убраны лишние история и SavedChanges
из визуального preview, сокращены данные последнего перехода и повторы клеток
при обмене с worker. [Изменения и повторные замеры](workflow-performance-2026-09-11.md).

Ближайшие задачи:

Подготовка Preview перенесена из потока обмена в worker-процесс после
раздельного измерения проверки ChangeSet, секций и GC. Максимальная пауза
уменьшилась с 677 до 394–408 мс, полное ожидание выросло с 2,49 до 2,60–2,69 с.
[Результаты и компромиссы](preview-responsiveness-2026-09-11.md).

После проверки предложений из чата приоритеты уточнены —
[актуальность замечаний, порядок и критерии готовности](next-priorities-2026-09-11.md):

Первые два пункта закрыты: локальный Apply/Undo/Redo не сканирует накопленный
block patch; карта проверяет известность в пределах текущего среза.
При 500k клеток Apply Python API сократился с 323 до примерно 0,5 мс;
fork и IPC остаются линейными. [Реализация, замеры и ограничения](world-patch-delivery-2026-09-11.md).

Один снимок в worker, типизированные команды EditWorkflow, task ID и явные состояния
runner реализованы. Проверены Cancel, потеря ответа, частичный сбой и повторное
открытие; GUI Save/Undo/Redo ускорились, Preview пока немного медленнее и RSS выше.
[Контракт и измеренные компромиссы](worker-lifecycle-2026-09-11.md).

Следующий этап выполнен: компактные ответы для обычных блоковых Apply/Undo/Redo,
ограниченная память и повторное использование страниц Object Search, адаптивные
Replace/Copy/Top surface и бюджеты Paste/Stack без Air.
[Результаты и границы](data-path-delivery-2026-09-11.md).

1. По профилю GUI определить оставшуюся стоимость render snapshots и resize. Полные

2. Проверить lifecycle и доступность команд на переходах preview/placement/search;

3. Укреплять публичные типы, ошибки и проверки CI отдельным этапом без массового rewrite.

Отдельно пройти ручной сценарий физическим тачпадом после переключения приложений.

## Сейчас: отработать маленький прототип

Открыть → полетать → выделить → preview → Apply/Undo → сохранить.
История, размещение с точной подстройкой, выбор материала и изменение границ
выделения уже есть. Повороты, отражения, оси перемещения, Keep placing и Stack реализованы;
проверки этапа — в [размещении](placement-stage.md). Условия Paste/Stack также готовы:
[Keep existing / Only material](destination-rules.md).

- Проверить трекпады и Windows/Linux; удержание клавиш, отпускание, фокус полей.
- Уменьшить паузу полной установки сцены; измерить память после Refresh и Undo.
- Проверить попадание в частичные модели; углы в пустоте уже ставятся через 1/2.
- Полёт остаётся без загрузок; кнопка/F5 явно обновляет ограниченную область.
  Частичные карты и повторное использование геометрии при F5 — только по замерам.

## Реализовано: история и размещение

Все шаги сессии хранятся во временном SQLite-журнале; RAM-кэш ограничен 500 000 ячеек и оценкой 64 MiB; временные буферы считаются отдельно.
Save сохраняет историю. Copy/Take/Duplicate/Paste/Import используют общий Clipboard
и один дух: курсор → фиксация кликом → оси/XYZ/стрелки → Review → Place. Геометрия при движении
не пересобирается. Take меняет источник только на Apply, вместе со вставкой в
одном Undo. Clipboard включает обычные сущности и NBT блоков; игроки исключены.
Отдельные действия Objects также сохраняются. Отмена сохраняет источник. Схематик растёт
при размещении за границами; Undo восстанавливает размер и origin.
Keep placing повторно использует дух, Take удаляет источник один раз.
Repeat selection задаёт число дополнительных копий, направление и зазор; весь повтор — один Undo.

Выбор сущностей кликом и всех в зоне, Move/Duplicate/Rotate/Delete и общий
инспектор NBT/инвентарей уже реализованы. Неизвестные поля модов сохраняются;
правила конкретных модов и нестандартные модели требуют отдельной поддержки.

Мир с DataVersion 2844–3955 редактируется локально в существующих чанках и секциях. F5 сохраняет
patch и историю за пределами нового окна. Отдельная кнопка Save world отправляет
накопленные изменения через core; Undo после Save создаёт обратный patch.
Проверены NBT, конфликты, внешние чанки, backup и полный GUI-сценарий. Перед большими
объёмами нужны замеры памяти глобального patch, длинной истории и дисковых копий.

## Реализовано: быстрый выбор материала

I / средняя кнопка берёт точный blockstate под курсором или прицелом, сохраняя
камеру и выделение. Общий To переходит между Fill/Replace; From и маска выбираются
отдельно через ту же панель. Catalog ищет ID/английские имена в локальных ресурсах;
In build показывает загруженную палитру, Recent сохраняет 12 последних материалов. Стрелки/Enter выбирают, Escape возвращает фокус без изменения.
Пипетка не читает блоки из preview/духа и не переносит содержимое контейнеров.

## Реализовано: границы выделения

Компактная панель Min/Max показывает крайние блоки включительно и мировые
координаты для мира. Общий шаг управляет Grow/Shrink со всех сторон и сдвигом
по шести направлениям. 1/2 и Set A/Set B независимо ставят углы в позиции
камеры, включая пустоту. Переход углов через друг друга нормализует границы;
сдвиг и изменение размера сохраняют сторону первого угла для Shift+click.
Ошибка не обрезает область. Наведение показывает будущие границы; A/B видны
в сцене. Изменение границ не сканирует блоки и не меняет мир.
Состав выделения раскрывается кнопкой Blocks: текстуры и количества без воздуха.
Подсчёт фоновый, только для открытой панели; устаревшие результаты отбрасываются.

## Следующие приоритеты

Поворот духа ±90° вокруг Y и отражения X/Z сохраняют точку привязки. Направленные
свойства меняются вместе с координатами; исходный Take-регион остаётся прежним.
Вычисления и сборка preview выполняются в общей фоновой очереди, Apply/Undo едины.

Порядок — наша оценка пользы для маленького редактора, не рейтинг популярности
команд. Проверять на четырёх задачах: стена, арка, повторяемый этаж и перенос дома.

| Порядок | Что добавить | Зачем |
|---|---|---|
| Готово | Оси блокового духа, Keep placing и Stack | Точно размещать и повторять фрагменты |
| Готово | Условия назначения Paste/Stack | Сохранять существующие блоки и заменять выбранный материал |
| Готово | Совместный перенос блоков/сущностей, поиск и удобный инспектор | Предсказуемо объединять постройки и находить нужные данные |
| База готова | Связное выделение, формы в GUI, смеси материалов, сравнение и восстановление | Редактировать сложные объекты и проверять результат |

Срез по высоте реализован: View → Height slice и кнопка All Y в статусе.
All layers / Up to Y / Single layer и Use camera height меняют сцену,
карты и выбор мышью. Мировой Y сохраняется при обновлении области и расширении
схематика. Скрытые данные сохраняются; выделение и операции остаются полными.
Автоматическое скрытие крыши и отдельная система слоёв пока избыточны.

Ориентиры шире WorldEdit:

- [Axiom Clone](https://axiomdocs.moulberry.com/builder/buildertools/clone.html):
  голограмма, точные сдвиги, ограничение осью, поворот и повторные копии.
  Для нашего тачпада шаг должен быть доступен клавишами и XYZ, без обязательного колеса.
- [Axiom Selections](https://axiomdocs.moulberry.com/editor/selections.html) и
  [Builder Tools](https://axiomdocs.moulberry.com/builder/buildertools/intro.html):
  Copy/Cut/Duplicate и условия Copy Air/Keep Existing. Берём небольшой общий набор действий.
- [Litematica](https://github.com/maruohon/litematica): работа со схематиками,
  клонирование, перемещение, заливка и удаление. Полезный ориентир для цельного
  сценария «загрузить образец → разместить», без собственной копии декодеров.
- [WorldEdit Clipboard](https://worldedit.enginehub.org/en/latest/usage/clipboard/) и
  [Selections](https://worldedit.enginehub.org/en/latest/usage/regions/selections/):
  точка привязки, маски вставки и изменение границ. Командную строку модов в GUI не переносим.
- [Structure blocks в Minecraft](https://www.minecraft.net/en-us/article/get-some-structure--blocks--your-life):
  сама игра тоже предлагает перенос построек через сохранённую структуру.
  Ориентир для явных размеров и координат, без добавления симуляции игры.

## Качество минимального интерфейса

- Постройка читается первой: спокойный светлый фон, одинаковая толщина рамок
  в пикселях, лёгкое наведение и более заметное подтверждённое выделение.
  Невидимые границы показывать сдержанным пунктиром, без постоянной пульсации.
- У духа видна точка привязки, размер W×H×D и режим «за курсором / закреплено».
  Недопустимое положение сопровождается короткой причиной; цвет не единственный сигнал.
- Изменение оси, масштаба окна или карты не искажает пропорции; боковые виды
  сразу сжимаются до квадратных иконок. Светлая тема и сохранение aspect уже реализованы.
- После асинхронного результата сохраняются фокус поля, введённый текст и
  камера. Вращение, панорамирование карты и ввод координат не активируют другие действия.
- Сохранение сообщает путь и фактический результат. Долгая работа показывает
  существующий маленький индикатор; быстрые действия обходятся без мигания панелей.
- Перед новыми инструментами пройти один цельный сценарий мышью и тачпадом:
  выделить, перенести, подправить, отменить, повторить, сохранить и открыть снова.
  Измерять задержки и память на реальной постройке, а не только на маленьком demo.

Операции GUI и Python используют общий API. Move/Paste/Stack читают неизменяемый
источник, чтобы перекрытие не затирало вход. Повороты и отражения сохраняют
согласованные состояния составных блоков. Сущности и биомы меняются только
отдельной явной операцией. Дробное масштабирование, симуляция Minecraft,
генерация отсутствующих чанков и совместное редактирование сейчас вне плана.
Подробный каталог будущих команд сохранён в [историческом плане](../structura-edit/structura-edit-roadmap-2026-09-08.md).

## Контракт записи мира

На позицию храним `before` и `after`, включая blockstate и block-entity NBT.
Возврат к исходному удаляет позицию из patch. Незагруженное не считается воздухом.
Refresh сохраняет локальные правки и исходное `before` для сравнения.

Перед записью перечитываем затронутые чанки:

| На диске | Действие |
|---|---|
| `before` | Записать `after` |
| `after` | Уже выполнено |
| Другое значение | Остановить Save, сохранить patch; Force ещё не реализован |

Остальные позиции сохраняются из свежего чтения. Будущий Force должен повторно
читать данные и разрешать только показанные конфликты, без скрытого перезаписывания.
Без конфликтов дополнительного диалога нет. Записи редактора сериализуются.
Перед записью сохраняется копия затронутых файлов с manifest. Частичная ошибка
сохраняет patch и сообщает путь backup. Подготовленные чанки проверяются чтением,
файлы повторно проверяются по хешам перед заменой. Undo создаёт обратный patch с такой же проверкой.

Эксклюзивная блокировка Minecraft и обязательный мод не требуются. Режим best-effort
не исключает гонку с игрой и не обещает атомарность между процессами. Следующие проверки —
большие регионы, частичные ошибки I/O и конкурентная работа с настоящей игрой.
Атлас не получает пиксели несохранённых правок.
