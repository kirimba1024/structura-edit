# macOS-приложение после обзора мира

11 сентября 2026. Следующий незавершённый шаг после
[реализации обзора](world-overview-implementation-2026-09-11.md) закрыт:
`dist/Structura Edit.app` и `dist/Structura-Edit-macOS-arm64.zip` пересобраны
из текущих wheels core/render/edit. Версии: Python 3.9.6, Qt 6.10.2,
VTK 9.5.2, meshoptimizer 0.2.30a0. Исходные незакоммиченные изменения сохранены.

Старое сборочное окружение содержало Qt 6.8.3 и не имело meshoptimizer.
Зависимости обновлены по существующему `macos-requirements.txt`. Первый frozen-прогон
обнаружил отсутствие метаданных meshoptimizer; spec теперь явно включает их
вместе с нативной библиотекой. Ошибка чтения версий записывает новый отчёт `failed`,
даже если на диске был прежний `passed`. Перед заменой приложения удаляется
старый `build.json`; новый создаётся только после успешной проверки и упаковки
и содержит версии зависимостей.

Проверка установки повторно использует `tests/smoke_overview.py` и его fixture.
В пакет входят эти два модуля; копии сценария и генератора мира не создаются.
Необязательный параметр assets позволяет проверять приложение с пустым каталогом
ресурсов, независимо от личного Minecraft. Результаты обзора входят в общий JSON.

Проверки из исходников, внутри собранного приложения и после распаковки ZIP
в `/private/tmp/structura-overview-portable-20260911` прошли:

- Bundled demo, настоящий Qt/VTK framebuffer и запуск worker.
- Поиск 70 контейнеров, пакетный Preview/Apply, Save/reload и Undo.
- Снимок шести сохранённых колонн, нативный QEM и публикация геометрии.
- Вращение без новой загрузки, A→B→C с сохранением документа, отмена движением.
- F5 с сохранением камеры, быстрая смена срезов, Cancel без автоповтора.
- Зум вокруг курсора и загрузка мировой карты.

Подпись исходного и распакованного приложения проверена `codesign --verify
--deep --strict`. При проверке переноса удалены `PYTHONPATH` и `PYTHONHOME`;
`frozen: true`, bundled demo находится внутри перенесённого `.app`.
Контрольные кадры сцены и карты проверены визуально. Ruff и `git diff --check`
прошли; отдельно воспроизведена замена старого успешного отчёта при отсутствующей
зависимости. Общие pytest не повторялись: изменения затрагивают упаковку и smoke.

[Данные проверок и хеши](macos-overview-delivery-2026-09-11.evidence.json).
ZIP занимает около 160 MiB. Сборка локальная, с ad hoc подписью, без notarization.
Проверена текущая macOS 26.6.2 arm64; минимальная macOS 13 и другие платформы
по-прежнему требуют отдельных прогонов. Ресурсы Minecraft не входят в пакет.

Следующий инженерный шаг — повторный профиль Take/Apply/Undo на 24 этажах
с новой базой, затем сокращение подтверждённых затрат обмена с worker и VTK.
Этот выпуск не заявляет устранение ранее измеренных пауз GUI.
