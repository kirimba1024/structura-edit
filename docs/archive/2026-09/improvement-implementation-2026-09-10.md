# Доработки Structura Edit — реализация 10.09.2026

Реализованы R1–R6 и минимальные F1–F4/D1–D3 из [плана](improvement-plan-2026-09-10.md).
Изменения находятся в workspace, без коммита и публикации. Существовавшие до этой
работы правки сохранены. Основные команды пользователя описаны в [README](../../../README.md).

Продолжение через сценарии стены, этажей, переноса и восстановления — в
[отдельном отчёте](improvement-workflows-2026-09-10.md): исправлена отмена расчётов
Planar/Paint, ускорен диагональный мазок и закрыт неявный Save изменённого источника
после восстановления через Python API. Последний полный pytest: **782 passed**.
Числа и границы ниже относятся к первоначальному этапу из 750 тестов.

## Контракты и алгоритмы

Состояние после Save хранится отдельным разреженным набором различий; полная копия
мира для индикатора не создаётся. Поля клетки сравниваются с отделёнными NBT-данными,
а позиции приводятся к общей системе координат. История и точка сохранения независимы.
Для сущности число скрытых изменений рассчитывается по итоговой позиции,
для удаления — по исходной; это не число всех прежних и новых занятых клеток.

Manifest проходит preparing → prepared → installing → complete. До prepared оригиналы
скопированы, синхронизированы и проверены. Preparing не блокирует новый Save: на этой
фазе мировые файлы ещё не изменялись. После отказа Restore сверяет реальные файлы с
хешами; установленная запись manifest не считается единственным свидетельством.
Save/Restore используют один advisory lock, temp-file → fsync → replace и синхронизацию
каталогов на POSIX. Перед каждой заменой повторно проверяется текущий хеш. Lock
координирует Structura, но не останавливает Minecraft или сторонний редактор; файл
может измениться после последней проверки. Фактическое отключение питания и гарантии
накопителя не проверялись, fault injection моделирует границы файловых операций.

Planar использует BFS по четырём соседям в плоскости одной грани. Extrude добавляет
p + k·normal, k=1…depth. Frame использует двумерную L∞-окрестность: внешняя рамка
Dilate(S,r) \ S, внутренняя S \ Erode(S,r). Для 5×7 и r=1 получены 28 внешних и
20 внутренних клеток. Перебор Frame ограничен |S|·(2r+1)².

Paint проверяет расстояние центра клетки до отрезка, читает одну исходную ревизию
и включает клетку один раз. None разрывает траекторию. Редкий и частый отсчёт одной
прямой дают одинаковый набор; неизвестную кривую между отсчётами это не восстанавливает.
Количество проверок ограничено 8·operation_limit, изменённых клеток — operation_limit.

Mix сохраняет алгоритм hash v1; anchor=world добавляет origin перед вычислением.
Условия сначала проверяют доступность клетки: отрицание не превращает неизвестное в
воздух. CellSet и общий API операций сохранены; GUI не содержит второй реализации
геометрии или форматов.

Локальное восстановление не загружает pickle из пользовательского файла: используется
версионированный JSON с типизированными Cell/Entity и NBT. Временная SQLite-история
по-прежнему внутренняя и использует pickle. Публикация checkpoint происходит только
после записи и проверки файлов; неудача публикации оставляет прежний указатель.
Для схематики проверяется исходный SHA-256, для мира перед окончательной записью
работают существующие конфликты patch. Источник автоматически не перезаписывается.

## Проверки

Полный pytest core + edit: **750 passed**, 19 предупреждений сторонних библиотек
и ожидаемых предупреждений о потерях конверсии. Ruff и git diff --check проходят.

Native Qt на macOS: общий smoke_gui, smoke_backup, smoke_world_edit,
smoke_destination_rules, smoke_placement, smoke_placement_tools,
smoke_clipboard_entities и smoke_improvements. Новый сценарий дополнительно запускался
с видимым окном: размеры ограничены текущим минимальным окном приложения; проверены
материалы, длинные поля, Mix/Condition, библиотека, preview и отмена мазка. Отдельно
проверены изображения QWidget и framebuffer VTK: QWidget.grab не захватывает OpenGL
так же, как screenshot сцены. Это не полный аудит доступности или физического ввода.

Проверки сохранения работают на временных мирах: создание и удаление файла,
ошибка до/после замены, 12 случаев отказа записи manifest, отказ замены/удаления при
Restore, сторонняя запись после review и во время Restore. Черновики проверены после
расширения схематики, с NBT/сущностями и с глобальными правками вне окна мира; отказ
публикации и повреждённые данные распознаются. Экспорт Sponge дополнительно прочитан
через независимый Amulet reader. Личные миры при проверках не записывались.

Во время native-проверок обнаружена и устранена регрессия: HeightSlice, добавленный
для отчёта, передавался как аргумент plan_stack. Отдельная проверка проходит через
worker execute('repeat', …) и проверяет одновременно результат и число скрытых клеток.
Авточерновик также ждёт окончания preview/размещения/мазка и не прерывает ввод.

Команды из корня workspace:

```bash
AMULET_LEVEL_CACHE_DIR=/private/tmp/structura-amulet-cache STRUCTURA_EDIT_DATA=/private/tmp/structura-implementation-data .venv-edit/bin/python -m pytest -q libs/structura-edit/tests libs/structura-core/tests
.venv/bin/ruff check libs/structura-core/src libs/structura-core/tests libs/structura-edit/src libs/structura-edit/tests
AMULET_LEVEL_CACHE_DIR=/private/tmp/structura-amulet-cache STRUCTURA_EDIT_DATA=/private/tmp/structura-implementation-data STRUCTURA_SMOKE_VISIBLE=1 .venv-edit/bin/python libs/structura-edit/tests/smoke_improvements.py
```

Для остальных smoke заменяется имя последнего скрипта; smoke_gui принимает путь к
`libs/structura-render/src/structura_render/data/examples/demo.nbt`. На этом Mac Qt
запускается вне sandbox, как описано в DEVELOPMENT.md.

## Измерения и пределы результата

Замер Python 3.9.6: сначала готовый ChangeSet, затем tracemalloc только вокруг
pickle protocol 5 + zlib level 1. Величины ниже относятся к одному синтетическому
образцу, не являются RSS или гарантией задержки на пользовательских данных.

| Образец | Оценка удерживаемых объектов | Pickle | Дополнительный Python peak | Время |
|---|---:|---:|---:|---:|
| 50 000 обычных блоков | 26,51 MiB | 3,67 MiB | 27,85 MiB | 0,107 с |
| 2 000 записей с NBT около 4 KiB каждая | 9,29 MiB | 8,03 MiB | 10,02 MiB | 0,012 с |

NBT образца содержит повторяющийся текст и хорошо сжимается. Пик сериализации
по-прежнему существует; при необходимости следующий шаг — измерить реальную большую
сессию, включая patch и рабочие копии, и только затем менять формат хранения.

Белый текст на новом accent #197e66: 4,9792:1 вместо 2,9834:1. Тема, Monocraft и
пиксельное оформление сохранены. Импорт базового structura_edit не загрузил Qt/VTK.
Для общей таблицы полных кубов и thumbnail используется базовый structura-render;
GUI остаётся optional. Работа проверена с текущими соседними checkout core/render.
Чистая установка опубликованных пакетов и согласование их релизов ещё не выполнены.

Машиночитаемые результаты: [evidence JSON](improvement-implementation-2026-09-10.evidence.json).
Логи и изображения текущего прогона находятся в `/private/tmp/structura-implementation-checks`,
`/private/tmp/structura-improvements-smoke` и отдельных каталогах старых smoke.

Следующие условные задачи исходного плана остаются отложенными: batch NBT по набору
результатов поиска, объёмное сглаживание/Flatten, биомы, внешние патчи, свободные повороты,
новые чанки, инсталлятор и проверка других ОС. Для них не добавлены фиктивные команды
или обещания поддержки. Пользовательская полезность каталога, плоских инструментов и
Paint ещё должна быть проверена на настоящих задачах редактирования.
