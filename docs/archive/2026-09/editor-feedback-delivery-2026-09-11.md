# Исправления редактора по замечаниям 11 сентября

Полный перечень: [34 пункта](editor-feedback-plan-2026-09-11.md). Дальняя геометрия и общий атлас поверхности: [план следующего этапа](world-distance-plan-2026-09-11.md).

## Управление и понятность

- Esc отменяет действие/выделение и возвращает Cursor → Look. Tab переключает оба режима. Двойной Esc за 600 мс открывает Save and exit / Exit without saving / Cancel; сохранение должно завершиться успешно. Поля, меню и диалоги имеют приоритет.
- Take переименован в Move; отдельного Move blocks в GUI нет. Copy кладёт в буфер, Duplicate сразу начинает размещение копии. Move удаляет оригинал только вместе с успешным Place и заканчивается после одного размещения. Keep placing оставлен в Options только для копий.
- Нижняя панель: иконка и подпись Select, Move, Duplicate, Fill, Replace, Erase, Paste, Inspect; остальное — More. Команды меню показывают поясняющие tooltip. Нет отдельной дублирующей ячейки 1×1×1 и подменю Blocks.
- Inspect показывает регион целиком: Blocks, Block data, Entities, поиск и открытие объекта. Для одного блока отображаются имя/координаты. Карточка показывает доступные сведения, частые материалы и автоматическое вращающееся превью; большая область получает явно обозначенный ограниченный обзор. Содержимое инвентаря можно применить даже во время загрузки иконок: одна ожидающая правка проверяет актуальность документа перед выполнением.
- Visible heights объясняет скрытие без удаления. Одиночные блоки и сущности подписаны в мире. Выделение контрастнее, граница загруженной области заметнее. Колонны чанков и сетка секций — отдельные переключатели. XYZ перенесены вверх влево.
- Новая schematic кадрируется с учётом размера окна и структуры. Refresh сохраняет мировую позицию камеры. Миникарта отмечает незагруженное и предлагает Load here; полёт сам не запускает чтение мира.
- History одна: All actions / Edits / Errors. Фоновые операции сохраняют время, параметры, результат, отмену и ошибки в ограниченный JSONL-журнал. Технические записи не добавляют Undo; восстановление требует явной кнопки и использует существующую историю текущего документа. Покадровое движение мыши не протоколируется.

## Корректность

- Вода учитывает wet/waterlogged-блоки: внутри жидкости нет отдельных кубов вокруг растений, на внешней границе растение не оставляет отверстие вместо воды. Ореол соседей участвует в геометрии и ключах кэша.
- Slices использует реальные блоки, включая полностью закрытые грунтом, независимо от наличия видимых 3D-граней. Шесть проекций проверяются тестом скрытого блока.
- Материал `ыminecraft:stone` отклоняется у поля до Preview; ID не исправляется молча. Walls — четыре вертикальные стороны, Shell — также пол и крыша.
- Общие преобразования core представляют 48 целочисленных ориентаций. Компактные ±90° и Mirror доступны для X/Y/Z. Clipboard применяет накопленную матрицу к оригиналу; полный цикл восстанавливает точные исходные клетки, NBT, сущности и якорь. Проверены Save/Reload/Undo.
- Minecraft не позволяет произвольно наклонить любой блок: сундук нельзя достоверно поставить вверх ногами или на бок, горизонтальные рельсы нельзя наклонить произвольно. Такие состояния отклоняются. Вертикальные отражения плит и ступеней меняют bottom/top. Направления взгляда сущностей преобразуются; произвольный roll и специфические позы модов не моделируются. Исходные неизвестные данные сохраняются, полный цикл обратим.
- Save world применяет патч к свежепрочитанным чанкам. Посторонние изменения в этих же чанках сохраняются; конфликт затронутой клетки требует разрешения. Физически запись и резервное копирование работают с region-файлами, а не с отдельными байтами блока. Семантически старый чанк целиком не подменяет свежий.

## Измеренная производительность

Собственное окно Qt 6.10.2, мир A в временной копии, viewport 2760 × 1602, без cProfile и параллельной нагрузки тестов. Значения — отдельные воспроизводимые прогоны на этой машине, не гарантия для любого мира. Сырые результаты: [JSON](editor-feedback-performance-2026-09-11.json). Команда повторения: `tests/benchmark_world.py`.

| Проверка | Радиус 6 | Радиус 8 |
|---|---:|---:|
| Загруженные блоки | 1 068 043 | 1 887 782 |
| Open до готовой сцены и карт | 6,35 с | 10,23 с |
| Refresh после смещения области | 5,64 с | 10,11 с |
| Повторный Refresh той же области | 2,73 с | 5,08 с |
| Save одной правки, весь GUI-цикл | 1,83 с | 3,42 с |
| Завершённые отрисовки при движении | 80,5/с | 29,5/с |
| Среднее время рендера | 8,80 мс | 19,12 мс |
| p95 интервала кадров | 16,77 мс | 90,04 мс |
| Акторы | 183 | 310 |
| Геометрия | 41,8 MiB | 70,0 MiB |
| RSS GUI + worker после Save | 2,12 GiB | 2,98 GiB |

Сумма RSS повторно учитывает часть общих страниц и не является пиком. Она показывает, что текущие Python-структуры всё ещё дороги на миллионах блоков. На r8 при Save максимальный наблюдавшийся интервал GUI-таймера составил 270 мс, на r6 — 125 мс: полностью исключить короткие задержки ещё не удалось.

Для r6 переход с акторов по 16³ на 32³ уменьшил их число 854 → 183, время рендера 30,5 → 8,8 мс и дал 23,6 → 80,5 завершённых отрисовок/с без упрощения блоков. 64³ отвергнуты: хуже отсечение и дороже локальное обновление; на r8 падали скорость полёта и Save. Участки отрисовки не меняют реальные чанки/секции Minecraft.

До укрупнения акторов, на r3, копии/кэш/запись ускорили повторный Refresh примерно 4,98 → 1,07 с, Save 2,17 → 0,72 с. Эти меньшие сцены нельзя напрямую сравнивать с r6/r8. Основные изменения: пакетное чтение, меньше глубоких копий, один плотный индекс для подготовки большой сцены, LRU геометрии, переиспользование акторов и региональных интерфейсов записи.

Каталог 20 000 материалов: последнее видимое открытие 0,087 с, повторное 0,004–0,016 с. Модель виртуальная, иконки запрашиваются только для видимых строк. 200 перемещений preview: в среднем 0,123 мс на обновление, без перестройки мешей.

## Проверки и оставшиеся ограничения

- 920 pytest core/edit и 425 pytest render (2 skipped); отдельные проверки всех осей и циклов, мокрой геометрии, закрытых блоков миникарты, кэша и соседей, свежей записи мира, Exit/Esc, виртуальных моделей и History.
- Native smoke: автоматическая карточка блока/манекена/области, узкое окно, размещение, повторные копии, инвентари, сущности и Undo. Все эти окна имеют временные данные и закрываются автоматически.
- Зависание карточки воспроизводилось в `pyvistaqt` paintEvent. Карточка переведена на SceneView с объединением render-запросов; повторный скрытый и видимый сценарии завершились успешно. Изображения GPU-превью проверены отдельно; обычный QWidget.grab не является корректным снимком всей композиции VTK на macOS.
- Защитное Restart needed остаётся правильным поведением при подмене кода работающего процесса. Разработка велась в отдельной копии; основная версия перенесена после закрытия старого редактора; smoke с обычными импортами основного проекта также прошёл.
- Стандартный радиус оставлен 6. Радиус 8 доступен как более тяжёлый режим; обещания 60 FPS для него нет. Для большого мира ещё важны компактное хранение/обмен и обзор дальнего рельефа; они перечислены в плане, без скрытой автоподгрузки.
- Возврат физического тачпада после переключения приложений требует ручной проверки на пользовательском устройстве; тесты событий не доказывают качество нативного захвата. Ранее собранная `.app` сама не обновляется от изменения исходников.
