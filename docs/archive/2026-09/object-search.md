# Поиск объектов

Find objects ищет по ID/словам в загруженных блоках и сущностях, включая текущие
правки. Block data означает блоки с NBT, без списка известных контейнеров.
In selection использует полуоткрытый регион; отсутствующий регион не подменяется
всем миром. Содержимое инвентарей и CustomName пока не являются поисковыми полями.
Сущности представлены корневыми записями; passengers доступны внутри их инспектора.

Панель шириной 384 px расположена слева поверх сцены; миникарта остаётся справа.
Сетка 4 px, строки 28 px, постоянная область списка. Viewport не меняется.
На странице до 64 результатов: один блок или несколько сущностей доступны для
Show / Select / Inspect. Объединять раздельные блоки их bounding box нельзя.
Show учитывает размеры сущностей и снимает срез, если объект за его пределами;
стены автоматически не скрываются. Исходные данные от поиска и Show не меняются.

Алгоритм и API находятся в object_search, GUI не импортируется. Worker хранит
один индекс текущего документа, состояния, ревизии, origin и dimension.
Координаты блоков — int32, материалы — коды палитры, наличие NBT — bool.
Текст сопоставляется с палитрой, затем фильтруются массивы координат. Полный NBT
блоков не разбирается; записи сущностей читаются один раз на ревизию.
Части индекса строятся по потребности: Entities не требует индекса блоков.
У каждой части бюджет 64 MiB; временная маска, индексы совпадений и исходный
снимок требуют дополнительной памяти. Список Qt получает только текущую страницу.

Ввод объединяется за 200 мс. Пока worker занят, хранится последняя цель.
Смена текста, страницы, региона или документа делает старый ответ неприменимым.
После правки и Undo индекс перестраивается; запрос без изменения ревизии использует
готовый. Закрытая панель не отправляет новые запросы. Общая кнопка Cancel может
остановить поиск; повторный запрос создаст новый worker при необходимости.

Проверки: test_object_search, тест worker в test_jobs и smoke_object_search.
Smoke проверяет страницы, модовый контейнер, Show, точный Select, групповое Inspect,
вложенный инвентарь с Undo, readonly, устаревший ответ, фокус и размеры.
На macOS закрытие QDialog может оставлять activeWindow пустым: инспектор по finished
возвращает главное окно и поле поиска, только если QApplication всё ещё активно.
Это воспроизведено отдельно на Qt 6.8.3 и проверено в видимом окне редактора.

Замер 09.09.2026 на мире A: 76 526 блоков, массивы индекса 1,30 MB,
первое построение 28,3 мс, медиана повторного поиска 0,17 мс. Через worker,
включая передачу снимка/результата и проверку версии кода: медиана 14,4 мс,
максимум 33,5 мс из 20 запросов; первый запуск worker — 187 мс.
Это задержка поиска без 200 мс debounce, не FPS. Команда benchmark_object_search
находится в DEVELOPMENT.md. Полный набор редактора: 301 pytest, Ruff и native smoke.

Референсы: [Blender Outliner](https://docs.blender.org/manual/en/5.0/editors/outliner/interface.html)
для поиска и фильтров списка объектов, [Qt Model/View](https://doc.qt.io/qt-6/model-view-programming.html)
для отделения результатов от их отображения.
