# Инспектор объектов

В `Inspect…` вкладка Structure показывает ленивое дерево. Find ищет имена, пути
и значения независимо от раскрытых ветвей. Числа и строки редактируются обычными
полями; `Edit value…` доступна кликом. Inventories находит вложенные предметы по
строковому `id`/`Id` и целому `count`/`Count`. `Edit count…` меняет количество,
`Open item…` раскрывает точный узел предмета. Не нужны известный контейнер, Slot
или сетка 9×3. Иконки предметов остаются следующим отдельным улучшением.

Все правки до Apply живут в черновиках выбранных объектов. Cancel закрывает их
без изменения документа. Apply выполняет одну общую операцию через существующий
worker и Undo. Неизвестные поля модов и типы чисел сохраняются; игровые правила
конкретного мода инспектор не угадывает. NBT text и редактирование целых контейнеров
остаются расширенным режимом с полным SNBT, а не обязательным способом изменить число.

## Разделение кода

- `nbt_values.py`: чтение пути, диапазоны чисел, точный ввод и независимые правки.
  Копируются только контейнеры вдоль пути; числовой массив копирует свой NumPy-буфер.
  Старый корень остаётся неизменным для поиска и отмены. List/Array сохраняют тип элементов.
- `nbt_search.py`: итеративный обход без Qt, поиск полей и предметов. На странице
  не больше 128 строк; обход ограничен 100 000 полей и 128 уровнями. `limited`
  явно обозначает неполный поиск. Полные данные доступны в Structure/NBT text.
- `nbt_search_ui.py`: одна текущая задача и последняя ожидающая цель; debounce 200 мс,
  отмена устаревшей задачи, отбрасывание устаревшего ответа. Один поток на инспектор;
  таймер работает лишь пока есть запрос. Поиск не запускает перерисовку сцены.
- `nbt_tree.py`: страницы ветвей и переход по точному пути без раскрытия всей коллекции.
- `nbt_value_dialog.py`: простой ввод, проверка диапазона до закрытия окна, Cancel.
- `object_inspector.py`: вкладки, выбор объекта, черновики и Apply. Готовые корни NBT
  приходят из worker; обычные правки передаются обратно без сериализации всего дерева в GUI.

Числовые поля не используют преобразование через float для целых: `Long` должен
сохранить и `9007199254740993`, и крайние 64-битные значения. Float/Double проверяют
конечность и переполнение. Byte со значением 0/1 не считается автоматически Boolean.
Строка вводится буквально, включая пробелы, кавычки и переносы.

После дочернего окна значения восстанавливается фокус инспектора; activateWindow
вызывается только когда приложение активно. Это тот же принцип, что при закрытии
инспектора и возвращении к поиску объектов.

## Основания

Qt требует работать с QWidget в главном потоке; поиск возвращает только данные,
а таблица обновляется в GUI. [Threads and QObjects](https://doc.qt.io/qt-6/threads-qobject.html).
QSpinBox принимает `int`; для полного диапазона NBT Long используем текстовый ввод
и точный Python int. [QSpinBox](https://doc.qt.io/qt-6/qspinbox.html).
Условия восстановления окна: [QWidget.activateWindow](https://doc.qt.io/qt-6/qwidget.html#activateWindow),
[QGuiApplication.applicationState](https://doc.qt.io/qt-6/qguiapplication.html#applicationState).
