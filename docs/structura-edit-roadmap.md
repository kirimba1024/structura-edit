## Выполнено: предсказуемые переходы

| Работа | Критерий и проверка |
|---|---|
| Приём фонового результата | `EditorDocument.replace` требует захваченный SessionToken. Поздний, повторный и конкурирующий ответ не меняет документ/selection/preview |
| Доступность команд | Общий снимок для Save/Apply/Discard, selection/operations/materials, inspect/export/copy/place, history seek и draft; тесты menu/button/handler, protected Apply и сохранения Connected во время поиска |
| Resize без сдвига | Словарная база не копируется и не перебирается. Apply/Undo/Redo сохраняют NBT, entities и независимость fork/snapshot; BlockArray и сдвиг координат остаются на полном пути |
| Material Mix | Исправлена подтверждённая потеря объекта при смене операции. Fill → Replace → Erase → Fill сохраняет Mix/условия и даёт прежний результат |

[Замеры и проверки этапа](archive/2026-09/editor-contracts-2026-09-11.json).
Для расширения на один блок при базе 500k: Apply движка 170 → 0,07 мс, без учёта
fork/IPC/GUI. Большой Take с отрицательным resize всё ещё даёт GUI gap около 409 мс.
**Открытая проверка:** native navigation требует разблокировать сеанс macOS;
`full` не считается пройденным. Готовность публичного релиза этим этапом не заявлена.
Предыдущий [этап сокращения контекста](archive/2026-09/context-compaction-2026-09-11.json)
сохранил исторические документы в архиве и оставил один план/контур проверок.

## Следующие задачи

| Приоритет | Задача | Граница и критерий |
|---|---|---|
| 1 | Паузы больших Preview и resize со сдвигом | Профиль native Take: rebase, render snapshots, приём/установка геометрии. Улучшение GUI gap подтвердить замером; NBT/entities, Undo и независимость снимков сохранить |
| 2 | Память длинных Python recipes | Определить контракт recipe с undo/redo, затем ограничить промежуточную историю. Итоговый diff и поведение исключений сохранить |
| 3 | Оставшиеся контракты по сценариям | World/overview и модальные команды; типы model/workflow, local/world coordinates, небольшие domain errors, точный CLI ImportError и один источник версии. Без массового rename и второго владельца состояния |
| 4 | Воспроизводимость вне workspace | Подключить существующую команду проверок к CI; сверить минимальные зависимости с выпущенными core/render. Windows/Linux, минимальная macOS и публичная подпись — отдельные проверки |

Внешние аудиты — гипотезы: задача попадает в очередь после проверки кода и сценария.
Не переносить сюда списки новых продуктов. Параллельные mutating workers, новый renderer,
engine distribution, plugin framework и массовая перегруппировка модулей сейчас не нужны.
Новые инструменты добавляются после проверки стена → этажи → перенос → Save → Undo →
recovery и ручного ввода физическим тачпадом.
