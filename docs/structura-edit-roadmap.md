## Выполнено: память и передача изменений

| Работа | Критерий и проверка |
|---|---|
| Большой Preview | Компактный pickle `_Cell`/`_Delta`: payload 57,625 изменений 4,22 → 2,52 MB. Контрольный native Take: максимальная пауза GUI 386 → 212 мс; общее время Preview почти прежнее |
| Длинные Python recipes | Промежуточная история использует существующую SQLite и кэш до 64 MiB, весь Undo/Redo сохраняется. Исключение, ошибка диска и Cancel очищают журнал, не меняют исходный документ/redo |
| Публичные контракты | Стабильный порядок diff, версия из package metadata, CLI объясняет только отсутствие GUI-зависимости и не маскирует посторонние ImportError |

[Проверки и ограничения замеров](archive/2026-09/recipe-preview-2026-09-11.json).
Recipe из 1000 edits: peak RSS 132 → 82 MiB, время 3,41 → 3,98 с; это ограничение
кэша ChangeSet, не всей памяти произвольного Python. Новые runtime-модули не добавлены.
Предыдущий [этап контрактов](archive/2026-09/editor-contracts-2026-09-11.json) закрыл
model-level acceptance, основные capabilities, Mix и resize без сдвига.
**Открытая проверка:** native navigation требует разблокировать сеанс macOS;
`full` не считается пройденным. Готовность публичного релиза не заявлена.

## Следующие задачи

| Приоритет | Задача | Граница и критерий |
|---|---|---|
| 1 | Оставшаяся задержка большого Preview | Профиль выявил полную `_check_change` в GUI; отдельно стоят resize со сдвигом и снимки. Сокращать проходы без обхода model validation. Замерить GUI gap; сохранить NBT/entities, Undo и независимость снимков |
| 2 | Оставшиеся контракты по сценариям | World/overview и модальные команды; типы model/workflow, local/world coordinates, небольшие domain errors. Без массового rename и второго владельца состояния |
| 3 | Воспроизводимость вне workspace | Подключить существующую команду проверок к CI; сверить минимальные зависимости с выпущенными core/render. Windows/Linux, минимальная macOS и публичная подпись — отдельные проверки |

Внешние аудиты — гипотезы: задача попадает в очередь после проверки кода и сценария.
Не переносить сюда списки новых продуктов. Параллельные mutating workers, новый renderer,
engine distribution, plugin framework и массовая перегруппировка модулей сейчас не нужны.
Новые инструменты добавляются после проверки стена → этажи → перенос → Save → Undo →
recovery и ручного ввода физическим тачпадом.
